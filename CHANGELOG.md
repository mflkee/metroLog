# Changelog

Все значимые изменения metroLog фиксируются здесь.
Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).
Версионирование: [SemVer](https://semver.org/lang/ru/). В git — тег `vX.Y.Z`.

Правило: запись добавляется на релизном шаге (`chore(release): vX.Y.Z`), см. раздел
«Версионирование» в `AGENTS.md`.

## [0.2.0] - 2026-10-08

### Added

- Модуль «Задачи»: доска и список, статусы, приоритеты, виды, теги и сроки.
- Участники задачи: один ответственный, несколько исполнителей, наблюдатели.
- Привязка оборудования к задаче (от 0 и более приборов).
- Чек-листы внутри задачи с прогрессом.
- Обсуждение задачи: упоминания через `@`, приватные заметки (видны операторам).
- Вложения на уровне задачи и сообщения.
- Подписка на задачу, email-уведомления при назначении, упоминании и смене статуса.
- Напоминания по дедлайну (джоб `app.tasks.task_reminders`), идемпотентные по дню.
- Раздел «Задачи» на карточке прибора и виджет «Мои задачи» на дашборде.
- Бейдж версии и канал `beta` в шапке.

### Changed

- Версионирование и релизный чеклист задокументированы в `AGENTS.md`.

### Fixed

- Дублирование этапов поверки/ремонта при создании (шаблонные + кастомные теперь не пересекаются).
- Настройки дашборда принимают виджет `my_tasks`.

## [0.1.0] - 2026-10-07

### Added

- Первая бета: реестр оборудования по папкам и группам, интеграция с Аршином,
  ремонты и поверки, журнал событий, мониторинг эталонов, комментарии и вложения.
- Watchdog доступности self-hosted раннера (`scripts/server/runner-watchdog.sh`).
